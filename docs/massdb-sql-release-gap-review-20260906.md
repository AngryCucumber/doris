## Docker 交付条件项

本次安装包采用主机原生构建，以下问题不影响已经验证的 tar 包；如果交付容器则需处理。

- `docker/runtime/fe/Dockerfile` 根据 `DORIS_VERSION` 是否为 3.x 以上选择 JDK。
  将独立产品版本 2.0.5-rc01 传入时会选 JDK 8，而 `bin/start_fe.sh` 明确要求
  JDK 17，并在其他版本上报错退出。这是启动条件冲突，不是仅凭编译器版本推测。
  产品版本号不应作为上游 JDK 兼容性判断依据。
- `docker/runtime/all-in-one/Dockerfile` 仍安装并配置 JDK 8。
- 运行镜像的 COPY/ADD 模式仍要求 `apache-doris-*` 目录，不能直接据此认定会接受
  当前 `massdb-sql-*` 安装包；all-in-one 的 broker 路径也与当前 extensions 布局不同。
- 对实际选用的镜像入口核对基础镜像 digest、系统包、JAR、原生库和声明材料。
  源码中的 FROM 名称本身不构成侵权结论；本次没有构建这些运行镜像。
